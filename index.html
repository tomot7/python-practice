開発の準備をしよう 💻

あなたは Debian系 Linux (pyenv環境) の説明を表示しています。

1. 端末（ターミナル）を開く

Linuxデスクトップ環境で「端末」や「Terminal」アプリを探して起動してください。黒い画面が表示されます。

2. Pythonが正しく入っているか確認する

ターミナルに以下のコマンドを半角英数字で入力し、Enterキーを押してください。

Terminal 
python --version

表示結果の例： Python 3.10.8 と表示されれば準備完了です！

3. 対話モードを起動する

ターミナルに python と入力してEnterを押します。

Terminal 
python

画面に >>> という記号が表示されましたか？これがPythonに命令を送る準備ができた合図（対話モード）です！

あなたは MacBook (標準ターミナル) の説明を表示しています。

1. ターミナルを開く

MacのFinderで「アプリケーション」＞「ユーティリティ」フォルダを開き、「ターミナル.app」を起動します。（もしくは、Spotlight検索で「ターミナル」と検索して起動します）

2. Python3が正しく入っているか確認する

ターミナルに以下のコマンドを半角英数字で入力し、Enterキーを押してください。

Terminal 
python3 --version

表示結果の例： Python 3.10.8（または3.x.xの別バージョン）が表示されればOKです！

3. 対話モードを起動する

ターミナルに python3 と入力してEnterを押します。

Terminal 
python3

画面に >>> という記号が表示されましたか？これがPythonに命令を送る準備ができた合図（対話モード）です！

【重要】OSによる操作とキーの違い
  • Linuxのキー： コピーは Ctrl + Shift + C、貼り付けは Ctrl + Shift + V になることが多いです。
  • Macのキー： コピーは Command ⌘ + C、貼り付けは Command ⌘ + V です。
  • 対話モードの終わらせ方（共通）： >>> の画面を終了して元に戻りたいときは、exit() と入力してEnterを押すか、キーボードの Ctrl + D を押してください。

レッスン1: 画面に出力しよう 💬

まずは、画面に文字を表示させる方法を学びましょう。Pythonで文字を表示するには print()（プリント）関数を使います。

手元のターミナル（対話モード >>>）に以下のように入力してみましょう。

Python対話モード 
print("こんにちは")

Enterキーを押すと、すぐ下に こんにちは と表示されます！

💡 中学生向けワンポイント解説

文字を囲んでいる "（ダブルクォーテーション）は、「これは文字データだよ！」とPythonに教えるためのマークです。半角で入力する必要があります。もし全角の ” を使うとエラーになるので注意しよう！

練習： 自分の名前を表示させてみよう。例えば print("太郎") のように入力してみよう！

レッスン2: 計算と変数 🧮

Pythonは、計算（算術演算）も大得意です。足し算や引き算の記号はキーボードから入力します。

1. 簡単な計算をしてみよう

  • たし算： + (プラス)
  • ひき算： - (マイナス)
  • かけ算： * (アスタリスク) ※ × ではありません
  • わり算： / (スラッシュ) ※ ÷ ではありません

対話モードで 5 + 3 や 10 * 3 と入力してEnterを押してみましょう。答えが返ってきます。

2. 変数（へんすう）を使ってみよう

プログラミングでは、値（数字や文字）を覚えておくための「名前がついた箱」を作ることができます。これを変数（へんすう）と呼びます。

Python対話モード 
x = 10
y = 5
print(x + y)

解説：

  • x = 10 は、「x という名前の箱に 10 を入れる（代入する）」という意味です。
  • print(x + y) は、箱に入っている中身を足し算して画面に表示させます。

レッスン3: 条件によって分ける（if文） 🛣️

「もし〜なら、◯◯する。そうでなければ、△△する」というように、条件によってコンピュータの動きを変える方法を条件分岐（じょうけんぶんき）と呼びます。

Pythonでは if（イフ）を使います。

Pythonコード例 
score = 80

if score >= 70:
    print("合格！おめでとう！")
else:
    print("もうすこし！がんばろう！")
⚠️ 超重要！インデント（字下げ）のルール

Pythonでは、if や else の次の行は、スペース4つ分右にずらして書きます。これを「インデント」と呼びます。インデントがあることで、「どこからどこまでが if の中の処理か」を判断しています。半角スペース4つでずらすのが基本です！

比較の記号（比較演算子）

  • a > b : a は b より大きい
  • a >= b : a は b 以上（同じか大きい）
  • a == b : a と b は等しい（イコールが2つ重なることに注意！）
  • a != b : a と b は等しくない

レッスン4: 繰り返し処理（for文） 🔄

同じ処理を何回も繰り返したいときは、for（フォー）文を使います。

例えば、画面に「ヤッホー！」と5回表示させたい場合、次のように書きます。

Pythonコード例 
for i in range(5):
    print("ヤッホー！")

解説：

  • range(5)（レンジ）は、「0から4までの5つの数字（0, 1, 2, 3, 4）を順番に用意する」という命令です。
  • 変数 i の中に、順番に数字が入りながら、インデントされた print() が5回実行されます。
💡 回数を確認してみよう

print(i) のように実行すると、i の中に今何の数字が入っているかを表示できます。プログラミングの世界では、数は 1 ではなく 0 から数え始める ことが多いです！

レッスン5: たくさんのデータをまとめる（リスト） 🗄️

これまでは、変数という「1つの箱」に1つのデータだけを入れてきました。しかし、部活のメンバー名やテストの点数一覧など、たくさんのデータをまとめて扱いたいときはリスト（別名：配列）を使います。

リストは [ ]（角カッコ）を使って作ります。

Pythonコード例 
fruits = ["りんご", "バナナ", "ぶどう"]
print(fruits[0])  # 一番最初の「りんご」を表示
print(len(fruits)) # リストの長さ（何個あるか）を表示

リストのポイント：

  • リストの中身を取り出すときは リスト名[番号] と書きます。
  • ここでも番号は 0番目 からスタートします！ fruits[0] は「りんご」、fruits[1] は「バナナ」になります。
  • len() は、リストの中にデータがいくつ入っているかを教えてくれる便利な命令です。

じゃんけんゲームを作ろう 🎮

最後に、これまでに学んだ 変数、if文、リスト を使って、コンピュータと対戦する「じゃんけんゲーム」のプログラムを書いてみましょう！

以下のコードをコピーして、手元のPython環境でファイルを作って実行してみましょう。対話モードではなく、エディタ（テキストエディタやVSCodeなど）に貼り付けて、janken.py という名前で保存して、ターミナルで python janken.py（Macは python3 janken.py）を実行することで動かせます。

janken.py 
# ランダムな機能を使う準備
import random

# 手のリスト
hands = ["グー", "チョキ", "パー"]

# プレイヤーの入力を受け取る (0, 1, 2)
print("--- じゃんけんスタート！ ---")
player_input = input("0:グー, 1:チョキ, 2:パー から選んで数字を入力してね: ")
player = int(player_input)

# コンピュータの手をランダムに決める
computer = random.randint(0, 2)

# それぞれの手を表示
print("あなた:" + hands[player])
print("相手:" + hands[computer])

# 勝敗を判定する
if player == computer:
    print("あいこです！")
elif (player == 0 and computer == 1) or (player == 1 and computer == 2) or (player == 2 and computer == 0):
    print("あなたの勝ち！")
else:
    print("あなたの負け...")

💡 コードの解説

  • import random : Pythonに標準で備わっているランダムな数を作る機能（モジュール）を取り込んでいます。
  • input() : 画面からユーザーが文字を入力するのを待ちます。入力された文字は int() を使って数字に変換して player という変数に入れています。
  • hands[player] : リストから入力された番号（0, 1, 2）に応じて手を取り出します。
  • randint(0, 2) : 0から2までのランダムな整数（0, 1, 2）を作ってコンピュータの手にします。
  • 最後の if-elif-else : じゃんけんのルールに沿って、あいこ・勝ち・負けを条件分岐で判定しています。
